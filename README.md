# もちもち ぺたぺた だいぼうけん

もちもちちゃん・ながいのくん＆みじかいのくん・うさぎのおとこのこ が主人公の、こども向け 3D よこスクロールアクション（全10ステージ）。
`index.html` ひとつで動きます（Three.js は CDN から読み込み）。

## あそびかた
| キー | うごき |
|---|---|
| ← → / A D | いどう |
| スペース / Z | ジャンプ（もう一度おすと かべジャンプ） |
| ↓ をおしっぱなし → ジャンプ | ためて スーパージャンプ |
| ↑ | ピンクのかべを のぼる |
| X / Shift（おしっぱなし） | むらさきの玉に のびーる → はなすと びよーん |

スマホではがめんのボタンでそうさできます。

## もちもちギミック
- **ぺたぺたかべ / てんじょう（ピンク）** … ぶつかると くっつく。のぼる・ぶらさがる・かべジャンプ
- **のびーる玉（むらさき）** … からだを のばして ぶらんこ
- **ぽよんゼリー** … たかくはねる
- うごく足場・エレベーター・うきしま・トゲ
- おちても すぐ まえの足場から やりなおせる「あんしんリスポーン」

## キャラのとくぎ
- もちもちちゃん：ジャンプおしっぱなしで ふわふわ ゆっくりおちる
- ながいのくん＆みじかいのくん：のびーるが とどくきょりが ながい
- うさぎのおとこのこ：2だんジャンプ

## GitHub Pages で公開
1. GitHub にリポジトリを作って push
2. Settings → Pages → Branch: `main` / `(root)` を選んで Save
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます

ローカルで遊ぶとき（ES Modules のため file:// ではなくサーバー経由で）:
```
python3 -m http.server 8000
```
